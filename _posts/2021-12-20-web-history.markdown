Since the inception of the first web page by Sir Tim Berners-Lee nearly 30 years ago, the Web has evolved considerably. This project is the systematic study of how
the Web has evolved over the years, from static HTML pages in the beginning to dynamic web pages now, from text-centric to more towards images and multimedia content.
